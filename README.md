# Simulador de Planificación de CPU - SIGET (C++)

Este repositorio contiene la solución en C++ para la simulación del planificador de procesos del **Sistema de Gestión de Tránsito (SIGET)**.

## Archivos
- `simulador_siget_prioridad-v2.cpp`: Código fuente con algoritmos de Prioridad por Alerta y Round Robin.

## Instrucciones de Compilación
```bash
g++ -O2 simulador_siget_prioridad-v2.cpp -o simulador
./simulador
